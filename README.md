# \# 隐私策略

# 

# \*\*最后更新日期：\*\* 2026年4月28日

# 

# 感谢您使用我们的应用。本隐私策略说明我们如何收集、使用和保护您的信息。

# 

# \---

# 

# \## 1. 信息收集

# 

# \### 本应用收集的信息类型：

# 

# | 类别 | 是否收集 | 说明 |

# |------|---------|------|

# | 设备信息 | ❌ 不收集 | |

# | 位置信息 | ❌ 不收集 | |

# | 联系人 | ❌ 不收集 | |

# | 照片/文件 | ❌ 不收集 | |

# | 账号信息 | ❌ 不收集 | |

# | 崩溃日志 | ❌ 不收集 | 如果未来集成分析SDK会另行通知 |

# 

# > ✅ \*\*本应用不主动收集任何个人信息\*\*。所有数据均在您的设备本地处理，不会上传到任何服务器。

# 

# \---

# 

# \## 2. 数据使用

# 

# 由于本应用不收集个人信息，因此：

# \- 不会与第三方共享您的数据

# \- 不会将您的数据用于广告定位

# \- 不会存储或传输您的个人文件

# 

# \---

# 

# \## 3. 第三方服务

# 

# 本应用目前\*\*不集成\*\*任何第三方SDK（如广告、分析、推送服务）。

# 

# 如果未来更新版本中需要集成第三方服务，我们会：

# 1\. 更新本隐私策略

# 2\. 在应用更新说明中告知您

# 

# 可能集成的第三方服务示例（仅供参考，目前未集成）：

# \- Microsoft Store 服务（分发和基本统计）

# \- 广告平台（如需要免费版本支持）

# 

# \---

# 

# \## 4. 数据安全

# 

# \- 本应用所有数据保存在您的设备本地

# \- 不会通过互联网传输您的个人数据

# \- 卸载应用时，所有本地数据将被清除

# 

# \---

# 

# \## 5. 儿童隐私

# 

# \- 本应用不针对13岁以下儿童

# \- 不会有意收集任何年龄用户的个人信息

# \- 家长无需担心儿童使用本应用时的隐私问题

#

# 如果本应用请求某些系统权限，仅用于基本功能，例如：

# \- \*\*存储权限\*\*：仅用于保存您主动选择的文件

# > 本应用不会在您未主动操作的情况下读取或上传您的文件。
